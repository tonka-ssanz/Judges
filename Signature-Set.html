Signature Set

Put every judge's signature file into one password-protected ZIP for the members area of the website. Rebuild it whenever a judge joins, withdraws or sends a new signature. Everything happens in this page; nothing is uploaded.

Signatures

Example signatures

Each judge's name comes from the file name, so it must match the judges list exactly. To fix a name, rename the file in your master folder and add it again.

Password

At least 12 characters. Use letters, numbers and keyboard symbols only.

Keep using the same password unless you mean to change it. Organisers need the new one before they can open a set with a changed password.

Add the real signature files to build a set.

Saved and checked

  1. Upload file.zip to the members area of the website.
  2. Replace the previous set there with this one, keeping the file name exactly SSANZ-Judge-Signatures.zip, so the download link in the trial tools keeps working. If your browser saved it as SSANZ-Judge-Signatures (1).zip, rename it first.
  3. If you changed the password, send the new one to organisers separately from the file.
  4. Keep your master signatures folder backed up, for example on a USB stick at home.

Good to know

  • Always rebuild from the master folder. Add, replace or delete the PNG file in your folder, then drop the whole folder in here. The new set then matches the folder exactly.
  • Lost the folder? Open the current set on the Open or check a set tab and choose Edit this set. Its signatures come back into this list.
  • What's protected: the signatures can't be seen or copied without the password. The judges' names are still visible as file names in the ZIP, which is how ZIP files work.
  • The password should be different from the website login. Send it by phone or in a separate email, never with the file. A yearly change, or when an organiser steps down, is a sensible rhythm.
  • Rebuild at least every 6 months, even if nothing has changed. Inside the set is a list of the judges and the date it was made, and the trial tools won't accept a set more than 6 months old. That stops organisers using an old copy that still holds a withdrawn judge's signature.
  • Opening it yourself: 7-Zip (Windows) or Keka (Mac) will open the set with the password. The ZIP opener built into Windows can't, because it doesn't understand this stronger protection.
  • Each file is checked when you drop it in. A warning means it may not have been made with the Judge Signatures page.
